# 样例场景

12份保单，每份都有基础投保与追溯加保。每三份中的第一份撤销指定加保，其他保单10月降低责任。P001全年3650.00元；P002的181、92、92天三段合计5030.00元，补缴1380.00元。脏批额外含完全重复、缺失保费、同版冲突、短行、空行与重复表头。legacy样例含GB18030中文与全角千分位。

## 退款场景（P013/P014）

- P013：责任降低产生真实退款 1380.00 元。issue 在 `ACC-P013` 实缴后，收款账户两次变更（`ACC-P013-N1`、`ACC-P013-NEW`，模拟规则变化使旧退款指令失效重算），而原付款账户 `ACC-P013` 已销户。按 `ORIGINAL_PAYER` 依据，指令置 `BLOCKED_CLOSED` 挂起人工核验，绝不改退最新账户，批次不可结案。
- P014：责任降低退款 920.00 元，原付款账户 `ACC-P014` 仍 open，生成 `READY` 指令，正常退还原付款人。
- 对照口径 `payee_basis=LATEST_ACCOUNT` 下，P013 会改退 `ACC-P013-NEW`，但指令显式标注“收款人可能非实际付款人”，默认不启用。
